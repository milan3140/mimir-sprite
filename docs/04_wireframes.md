# 04 · Wireframes(ASCII)

座標假設:精靈貼螢幕**右緣**(`anchorEdge:'right'`)。bubble 從 avatar **靠中心側(左側)** 冒出。左貼邊時鏡像。

## A. 收合(預設)— 只有會動的 avatar
```
                                      screen edge →┊
                                        ╔════════╗ ┊
                                        ║  ▟▙▟▙  ║ ┊   ← avatar (8-bit, idle 動畫)
                                        ║ ▐ ◑◑ ▌ ║ ┊     透明背景、可拖動移位
                                        ║  ▜▛▜▛  ║ ┊     小狀態點:●working ●resting
                                        ╚════●═══╝ ┊
                                      (其餘整窗透明 + click-through)
```
- mode 用 avatar 動畫狀態表現:idle=待機晃動、working=走動/專注、resting=打盹 Zzz、talking=講話(冒 bubble 時)。
- 角落一顆極小狀態點(working 綠 / resting 黃 / thinking 紫脈動),不干擾。

## B. Hover 展開 — 待辦清單 Panel(向左展開)
```
   ┌───────────────────────────────────┐ ╔════════╗
   │  Mimir          [☕]        [🚫]   │ ║  ▟▙▟▙  ║   ☕=休息  🚫=隱藏
   │ ───────────────────────────────── │ ║ ▐ ◑◑ ▌ ║
   │ ⠿  Draft Q3 report        ▶  🧠 🗑 │ ║  ▜▛▜▛  ║
   │ ⠿  Call supplier          ▶  🧠 🗑 │ ╚════════╝
   │ ⠿  Fix login bug   ‖ ✔    🧠 🗑   │   ← active:顯示 暫停‖ + 完成✔
   │ ⠿  Review PR #42          ▶  🧠 🗑 │
   │ ⠿  Plan offsite           ▶  🧠 🗑 │
   │ ───────────────────────────────── │
   │ [＋ 新增待辦…                    ⏎] │   ← 底部 input(需求 4)
   └───────────────────────────────────┘
```
圖示對照(實際用 Lucide,純 icon):`⠿`=GripVertical 拖曳把手、`▶`=Play 開始、`‖`=Pause 暫停、`✔`=Check 完成、`🧠`=Brain 思考、`🗑`=Trash 刪除、`☕`=Coffee 休息、`🚫`=EyeOff 隱藏、`＋`=Plus。

互動:
- **拖曳**:抓 `⠿` 上下拖,放開即時更新 `order`(需求 3)。
- **icon 顯隱**:item 預設只顯示 `▶ 🧠`;hover 才浮 `🗑`;active 項顯示 `‖ ✔`、隱藏 `▶`。
- **點項目主體(非 icon 區)** → 開「項目詳情」(下方 E),看 notes/附件/記錄。帶附件的項目在標題右側顯示一個小 📎。
- **新增對話框可貼圖**:input 聚焦時 Ctrl+V 貼截圖 → 縮圖排在 input 上方待送出,送出後掛到新 todo 的 `attachments`(需求補充)。
- **前三項**標記(極淡左緣序號或微光),呼應 thinking 候選池。
- panel 用 `setBounds` 往左加寬,avatar 不動。

## C. 對話框堆疊(thinking 輸出,需求 7)
逐句出現;新句出現在 **avatar 中心側固定錨點**,舊句往上頂,像堆積木。最多同時可見 3 句;第 4 句出現時第 1 句已 fade 完全消失。

```
 T0  第1句出現(錨點位置)
        ┌──────────────────────────┐ ╔════╗
        │ ① 先確認 Q3 數據來源齊全 ◗│ ║◑◑║
        └──────────────────────────┘ ╚════╝

 T1  第2句出現於錨點,第1句上移貼齊其上緣
        ┌──────────────────────────┐
        │ ① 先確認 Q3 數據來源齊全 │
        ├──────────────────────────┤ ╔════╗
        │ ② 預留 2 小時整理圖表    ◗│ ║◑◑║
        └──────────────────────────┘ ╚════╝

 T2  第3句出現;第1句開始 fade out(half)
        ┌──────────────────────────┐
        │ ① …(opacity 0.4 漸隱)   │
        ├──────────────────────────┤
        │ ② 預留 2 小時整理圖表    │
        ├──────────────────────────┤ ╔════╗
        │ ③ 需要去年同期報告對照   ◗│ ║◑◑║
        └──────────────────────────┘ ╚════╝

 T3  第4句出現;第1句完全消失(從 DOM 移除),②③上移
        ┌──────────────────────────┐
        │ ② 預留 2 小時整理圖表    │
        ├──────────────────────────┤
        │ ③ 需要去年同期報告對照   │
        ├──────────────────────────┤ ╔════╗
        │ ④ 提前一天寄會議邀請     ◗│ ║◑◑║
        └──────────────────────────┘ ╚════╝
```
- `◗` = 指向 avatar 的小箭頭(靠中心側)。
- 出現節奏:每句間隔約 `--dur-slow`×N(預設每 2.2s 一句,可設定);串流由 main `think:bubble` 事件逐句推。
- **點任一 bubble** → 開 `TranscriptModal` 看整篇(需求 7)。
- bubbles 全消失後 → 仍可 hover avatar 開 panel → 點該 item 的 `🧠` 歷史或 item 上的「對話」標記回看(需求 7)。
